# Jackbox research and first batch

Reviewed 2026-09-08 using Jackbox's official game and pack pages. User selected six games. These are new implementations of familiar formats, with original names, prompts, art, rules details and presentation. Music is reserved for the user.

## Selected games

| New game | Format reference | Core loop | Planned players |
| --- | --- | --- | --- |
| Quip Clash | [Quiplash](https://www.jackboxgames.com/games/quiplash) | Write funny answers to original everyday absurdity prompts, then vote in anonymous head-to-head matchups. | 3–10 |
| Sketch Bluff | [Drawful](https://www.jackboxgames.com/games/drawful-2) | Each phone gets a secret absurd drawing prompt and draws it. | 3–10 |
| Tall Tales | [Fibbage](https://www.jackboxgames.com/games/fibbage) | Players invent convincing false answers to unusual factual fill-in-the-blank questions, then identify the true answer among everyone's lies. | 3–10 |
| Shirt Show | [Tee K.O.](https://www.jackboxgames.com/games/tee-k-o) | Everyone draws original doodles and writes short slogans; shuffled contributions go to other players to combine into funny shirt designs. | 3–10 |
| Odd One In | [Fakin' It](https://www.jackboxgames.com/games/fakin-it) | A hidden bluffer receives only a broad answer category while everyone else sees the same secret question. | 4–10 |
| Quiz Panic | [Trivia Murder Party](https://www.jackboxgames.com/games/trivia-murder-party) | A family-friendly runaway quiz-show laboratory. | 2–10 |

Player counts above are implementation targets, not claims about Jackbox or tested support. All six start with a shared display and portrait phone controllers. No audience scaling or phones-only claim in this batch.

## Shared quality bar

Original local content, no scraped prompt banks or Jackbox assets; no paid services needed at play time. Server owns scoring, time and secret information. One room/QR/session serves all games. Each game includes deterministic rules tests, complete results and replay, bounded disconnect behavior, and a handoff. Browser QA was subsequently authorized and is tracked in [BROWSER-QA.md](BROWSER-QA.md). Physical phone, TV and hardware performance checks remain separate pending gates.
